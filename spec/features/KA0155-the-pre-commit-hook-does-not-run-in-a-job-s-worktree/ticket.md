## Description

F2 of KA0152 (spec/features/KA0152-the-home-page-reaches-a-jury-estimate-of-8-5-scored-blind-with-its-motion/findings.md).

- Kind: build
- Found by: 2026-11-05-worker-e334f830 (worker), 2026-11-05
- Where: `.husky/`, `core.hooksPath = .husky/_`
- What: `git config core.hooksPath` is `.husky/_`, but a fresh worktree has no `.husky/_` (it is generated by `husky`, and `bun run prepare` fails with `could not lock config file .../.git/config: Permission denied`), so commits in the job ran without `lint-staged` and `astro check`. This branch ran `bun run lint` and `bun run check` by hand instead.
- Suggestion: have the job set-up run `husky` from the main checkout before creating worktrees, or point `core.hooksPath` at a tracked folder; stays out of KA0152.
